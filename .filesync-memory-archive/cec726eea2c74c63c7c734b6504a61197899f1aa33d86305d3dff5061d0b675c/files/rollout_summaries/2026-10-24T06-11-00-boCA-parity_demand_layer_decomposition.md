# 按层分解需求的奇偶性对应关系

Rollout context: 用户在讨论由坐标变化对应需求条件、并尝试按分层量分解最少选边问题。

## Task 1: 识别三类坐标变化满足的需求

Outcome: partial

Key steps:

- 用户指出：\((y-1,x+1)\) 和 \((y+1,x-1)\) 分别满足两类同奇偶性条件，而 \((y+1,x+1)\) 满足 \(u\) 的条件。
- 助手将其具体化为：\((y-1,x+1)\) 满足 \(u,v\) 的两个 \(d_0\) 需求；\((y+1,x-1)\) 满足 \(u,v\) 的两个 \(d_1\) 需求；\((y+1,x+1)\) 满足 \(u\) 的两个需求。
- 引入分层量 \(s(v)=d_0(v)+d_1(v)\)：异号情况连接同一层；同号情况连接相差 2 的层，但只满足较大 \(s\) 端的两个需求。因此每条边实际满足的需求归属于同一个 \(s\) 层。
- 对话停留在提出待证明问题的阶段：尚未完成“各层独立优化并将最少边数相加”的严格证明，也没有验证跨层边不会造成选择牵制。

Reusable knowledge:

- 该建模中应按 \(s(v)=d_0(v)+d_1(v)\) 分层，并检查每条候选边所满足的需求是否完全落在单一层内；若成立，独立求解各层是自然的分解方向。

References:

- 用户原话："(y - 1, x + 1) 和 (y + 1, x - 1) 分别满足两个同奇偶性的条件，(y + 1, x + 1) 满足 u 的条件"
- 关键定义：\(s(v)=d_0(v)+d_1(v)\)
- 尚待证明：跨层边是否会让两层的选边相互牵制。
