## Task 2: P4802 路短最

Outcome: success

Key steps:

- 发现原程序输出 `f[n-1][z-1]`，错误地要求路径经过所有城市；题目只要求从 0 到 `n-1` 的不重复路径。
- 反例：
  ```text
  3 1
  0 2 5
  ```
  正确答案为 `5`，原程序输出 `-999999995`。
- 修正版对所有集合 `j` 取 `max(f[n-1][j])`，并在转移前检查状态可达和边是否存在；复杂度保持 `O(n^2 2^n)`。

## Task 3: P11267 王国边缘

Outcome: success

Key steps:

- 找到末尾不足一周期且区间内没有 `1` 时，原代码直接跳到全串最后一个 `1`，可能跳过当前周期中更近的 `1`。
- 反例：
  ```text
  8 9 1
  10000100
  3 1
  ```
  正确落点为 `9`，原程序输出 `6`。
- 修正版增加从当前位置向左维护的最近 `1` 指针；只有当前周期左侧不存在合适的 `1` 时才使用上一周期的全局最后一个 `1`。倍增结构保持不变，复杂度为 `O(70n+61q)`。
